In Small Data, Big Dreams: Minimal Computing for Data Collection & Visualization, we are learning to use GitHub and open source tools to make our project data available to the public. We brushed up on some web basics, learned a few of the principles of minimal computing, and used Collection Builder to set up a template for this week's project. <a href="https://literarysara.github.io/dreamlab2025/">Here is mine</a>, although I haven't added or modified anything beyond my name. 

We also heard a guest lecturer speak about data rescue, and the many community projects to preserve public data that is being removed from federal websites. For example, the <a href="https://edgi-govdata-archiving.github.io/j40-cejst-2/en/#3/33.47/-97.5">Climate and Economic Justice Tool</a>, an interactive map that is rich with data about the intersection of environmental justice, public health, and more. I had never seen this tool when it was publically available, although it is exactly the kind of tool I like to use, collect, and share with my fellow volunteers. Now it lives on GitHub. 

## Building a Simple Website with Eleventy and GitHub Codespaces

At lunch, there was an optional workshop to use GitHub to set up a blog--this very blog! Although, to be honest, this is my third attempt. During my first attempt, I missed a crucial step and lagged hopelessly behind. Then the internet dropped and many of us lost our connection to Codespaces, which means that we had to start over. That time I felt that I had a better handle on GitHub and was able to keep up with the workshop. But while I was tweaking my blog during the coffee break that afternoon, I somehow deactivated my live site and couldn't figure out how to bring it back online. So I started again, feeling that I could use the practice.

## Iteration, Failure, & Tic Tac Toe

After 5, we gathered back in the library for a session with two game designers, who put us into groups and asked us to redesign Tic Tac Toe so that it wasn't so boring and predictable. None of us succeeded, but failing was surprisingly fun. We tried altering elements of the objects (different shapes instead of Xs and Os), playspace (circular board instead of grid), goals (cooperative instead of competitive), rules (you can go around corners), and actions (throwing markers at the board instead of marking it).
