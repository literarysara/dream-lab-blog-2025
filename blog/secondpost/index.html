Today we jumped right into data wrangling by downloading a dataset from the Institute of Museum and Library Services (IMLS). We did a close reading, for lack of a better term, examining the site and the data itself to get a feel for what we might find there and how it is arranged. We learned the basics of data cleaning--or data wrangling, as our instructors preferred, since the data itself was fairly clean but needed some modifications to work with Collection Builder. We then spent some time organizing the data ourselves: adding filters, deciding which rows and columns to keep, modifying some abbreviations so they would display nicely on our future websites.

From there, we took a similar approach to the contents of the Collection Builder repository we downloaded yesterday: examining all its different component parts, guessing (and eventually being told) how they worked together in a sort of code ecosystem to build a website. This was both familiar and not, to me; the languages GitHub pages use look very different from both the HTML I remember from growing up and the Drupal and Pantheon pages I update for work. But the more time we spent exploring and discussing them, the more comfortable I felt.

Three Extremely Simple DH Tools

At lunch, we had a short workshop on three free tools we could incorporate into our work. Voyant is a text analysis tool; I fed it a URL for the full text of Moby Dick, and it gave me several visualizations (including a word cloud and a line graph) to show that the word "whale" appears more often than any other, and it's not even close. Timeline.js can be fed a template spreadsheet filled out with text and media to generate a timeline; to my surprise, I remembered using this tool to create a timeline about food and feminism. I was also surprised to learn about Storymap.js, a simpler free version of the Storymaps tool I've used from ArcGIS. Seems to work best with specific points on a map, illustrated with images or video.
